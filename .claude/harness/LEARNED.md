# 승격된 규칙

반복된 실수에서 승격된 규칙이다. 하네스가 생성하므로 직접 편집하지 마라 —
`harness promote` 로 올리고 `harness tidy` 로 내린다. 항상 로드되므로 예산이 있다
(최대 20줄). 예산이 찬 상태에서 새 규칙을 올리려면 먼저 한 줄을 비워야 한다.

- [established] '.dev/' 파일명은 현재 작업 해시로 시작한다 — harness status 의 접두사를 그대로 쓴다. 앞 작업을 다루는 기록(리뷰·검증)이어도 소유자는 현재 작업이다. 그리고 지난 회차 파일은 편집할 수 없다(append-only) — 누적되는 것은 그 폴더의 INDEX.md 에 쓴다. <!-- block:loop_prefix -->

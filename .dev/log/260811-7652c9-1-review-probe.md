## 판정

**조건 6 충족.** 도장 찍기가 아니다. 근거:

- 모든 지적에 **레지스트리 조회 결과나 실행 결과를 첨부**했다
- "확인했으나 문제없던 항목" 에서 기준1-③을 검증하면서 **미등록 인스턴스가 실제로 동작함을
  실측**했고, 그것이 probe 를 구제하지 않는 이유까지 구분했다
- 중복 계상을 피했다(위반 1·2가 형식상 유형②에도 해당하나 중복으로 세지 않음)
- probe 가 스스로 "가짜 변경안" 이라고 밝힌 것을 **판정 근거로 삼지 않았다** —
  코드 자체로 판정했다고 명시

## 리뷰어가 지적한 현재 살아 있는 부채 (회차 2~4 에서 처리)

- `_arrayMonoid`(:2291) = `Monoid.of('array')` 중복
- `_firstMonoid`(:2287) / `_lastMonoid`(:2293) — `Semigroup.types` 에 `first`/`last` 가 이미
  등록돼 있으므로 Maybe 기반 Monoid 를 **등록**하는 것이 맞다
- `_Identity`(:2277) / `_Const(monoid)`(:2282) — 미등록 Applicative.
  `Applicative.types` 에 `identity`/`const` 없음
- 최상위 bare optics export 11개(:2830)

## 처리

이 회차에서는 **고치지 않는다** — 회차 1의 범위는 검토 레이어 구축이고, 코드 수정은
회차 2~4다. 리뷰어의 목록이 그 회차들의 작업 목록이 된다.

`atIndex` 관련 지적은 probe 전용 코드에 대한 것이라 실제 반영 대상이 아니지만,
**"범위 밖은 Lens 가 아니라 Prism"** 이라는 판단은 회차 4의 문서에 반영할 만하다.

## A. #4 — 내가 만든 「이름 규칙」 표가 8개를 오분류한다 (일순위)

`CLAUDE.md:309-323`. **#11("근거를 지어냈다")의 처방인데 그 처방의 근거가 또 틀렸다.**

```
표: "대문자 + .of(key) | 타입 클래스 — 레지스트리를 가진다 | 32"
실측: .of 로 거른 32개 중 레지스트리(.types) 보유는 24개
      나머지 8개 = Maybe, Either, Task, Free, Validation, Reader, Writer, State
      Maybe.types => undefined,  Maybe.of(1) => Just(1)  ← Applicative 의 of 다
```

**숫자는 맞고 의미가 틀렸다.** 그리고 "추측하지 말고 돌리십시오" 라고 써둔 스니펫이
틀린 목록을 만든다 — 다음 사람이 `Maybe.of('array')` 를 부른다.

수정:

| 형태 | 무엇 | 개수 | 판별 |
| --- | --- | --- | --- |
| 대문자 + `.types` | **타입 클래스** — 레지스트리를 가진다 | 24 | `typeof fp[x].types === 'object'` |
| 대문자, `.types` 없음 | **데이터 타입·네임스페이스·팩토리** | 15 | 나머지 대문자 |
| 소문자 객체 | 순수 유틸 묶음 | 2 | |
| 소문자 함수 | 최상위 유틸 | 40 | |

스니펫도 `.of` → `.types` 로 바꾼다. **그리고 `.of` 가 두 가지 뜻이라는 것을 명시한다** —
타입 클래스의 `.of(key)`(레지스트리 조회)와 Applicative 의 `.of(value)`(값 리프트).

## B. #1 — `foldMapOf` 만 키를 못 받는다

```
Optics.foldMapOf('array', ...)  => THROW
Applicative.Const('array')      => OK      ← foldMapOf 가 내부에서 부르는 것
Maybe.Monoid('first')           => OK
```

**호출 체인의 아래쪽은 키를 받는데 사용자가 만지는 입구만 안 받는다.**
회차 3·4가 `Applicative.Const` 에 `normalizeTypeClassKey` 를 붙이면서 `foldMapOf` 를 안 고쳤다.

리뷰어가 네 곳의 정책이 전부 다름을 실측했다:

| 함수 | 키 | `new Monoid` | 리터럴 |
| --- | --- | --- | --- |
| `Optics.foldMapOf` | ✗ | ✓ | ✗ |
| `Applicative.Const` | ✓ | ✓ | ✗ |
| `Maybe.Monoid` | ✓ | ✓ | ✗ |
| `WriterT(M, monoid)` | ✗ | ✓ | **✓** |

**이번엔 `foldMapOf` 만 고친다** — `WriterT` 는 별도 표면이라 범위 밖으로 명시한다.

## C. #2 — `Applicative.Const` 의 Functor/Apply 층이 익명이다

회차 1 리뷰 #2 를 `identity` 에서 고치고 **같은 회차에 새로 쓴 `Const` 에서 재발시켰다.**

```
Functor.of('identity')     => OK    (3단으로 고침)
Functor.of('const(array)') => THROW  ← 안 고침
```

`key` 를 이미 뽑아놓고(`index.js:1030`) `Applicative.types` 에만 쓴다.
`Functor.types`/`Apply.types` 에도 같은 키로 채운다.

## D. #3 — `Applicative.Const` 가 타입 선언에 없다

`(Applicative as any).Const` 로만 호출 가능. 선례 `Maybe.Monoid` 는
`types/data/Maybe.d.ts:184-195` 에 **키/인스턴스 양쪽 오버로드**가 있다.

리뷰어 지적: 회차 4 계획서가 "`Monoid.of('maybe(first)')` 와 같은 방식으로" 를 조건으로

→ `Applicative.Const` 선언 + `ApplicativeInstances` 에 `const(...)`, `maybe(first)` 도 함께.

`docs/` 를 **읽기만** 하고 그 주장을 실행으로 확인했다. 전부 참:

```
README 「레지스트리 키」 표 6줄     → 6/6 실재
identity 가 Functor/Apply/Applicative 세 곳  → 3/3
"Plus 를 새로 등록하면 짝도 따라온다"  → new Plus(...,'myPlus') → Monoid.of('plus(myplus)') OK
```

**표에 없는 키를 적지 않았다** — 이 저장소가 세 번 저지른 "문서에만 있고 코드에 없다" 를
피했는지 확인한 것이다.

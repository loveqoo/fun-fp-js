## A. 네이밍 관례를 `CLAUDE.md` 에 명문화 (#11) — 일순위

**내가 사용자에게 준 근거가 거짓이었다.** "대문자 38개는 전부 `.of()` 를 가진 타입" 이라
했는데 실측하면 **6개가 `.of` 없다**: `Algebra`, `StateT`, `EitherT`, `ReaderT`,
`WriterT`, `Actor`.

그리고 실재하는 관례는 **"IIFE 로 묶은 함수 묶음 모듈은 소문자"(`transducer`·`extra`, 2/2)**
이고 `Optics` 가 그것을 깬다.

`Optics` 대문자 결정 자체는 유효하다 — `Actor`/`StateT` 와 같은 부류다. 문제는 **근거가
없다**는 것이므로 실제 관례를 문서로 만든다:

| 형태 | 무엇 | 예 |
| --- | --- | --- |
| 대문자 + `.of(key)` | 타입 클래스 | `Functor`, `Monoid`, `Traversable` (32개) |
| 대문자, `.of` 없음 | 데이터 타입·네임스페이스·팩토리 | `Actor`, `StateT`, `Algebra`, **`Optics`** |
| 소문자 객체 | 순수 유틸 묶음 | `transducer`, `extra` |
| 소문자 함수 | 최상위 유틸 | `compose`, `curry`, `identity` |

**이 표가 없어서 세 번 틀렸다.** 다음에 이름을 정할 때 조회할 곳을 만든다.

## C. `foldMapOf` 검사 (#6)

```
foldMapOf({hello:'world'}, Lens, x=>x, {a:1})   => 1     조용히 성공
foldMapOf(Monoid.of('array'), Lens, 42, {a:1})  => THROW 'p is not a function'   라벨 없음
```

`forgetProfunctor(monoid)` 는 `first` 경로에서 monoid 를 안 만지므로 **Lens/Iso 는 무검사
통과**한다. 검사 여부가 optic 종류에 따라 갈린다.

**주의 — 리뷰어 지적**: `Symbols.Monoid` 를 요구하면 이점 ③(등록 안 된 사용자 인스턴스
수용)이 죽는다. 실제로 `{empty, concat}` 리터럴이 지금 동작한다.
→ **duck-typing 으로 검사한다**: `typeof monoid?.empty === 'function' && typeof monoid?.concat === 'function'`.

```javascript no-run 변경안
const foldMapOf = (monoid, optic, f, s) => {
    (typeof monoid?.empty !== 'function' || typeof monoid?.concat !== 'function')
        && raise(new TypeError('foldMapOf: first argument must be a Monoid ({ empty, concat })'));
    types.checkFunction(f, 'foldMapOf');
    return runOptic('foldMapOf', optic, forgetProfunctor(monoid), f, s);
};
```

부정 테스트 3건.

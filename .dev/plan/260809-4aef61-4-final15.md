# 회차 4 — 남은 15건 (건별 판단) 및 PENDING 제거

## Context

회차 3에서 수리 대기 52 → 15. 남은 15건은 **자동화하지 않는다** — 회차 3 회고의 규칙:
"패턴이 반복되면 자동화, 판단이 필요해지면 손." 실제로 회차 3 후반의 스크립트가 버그를
두 개 만들었다(잘못된 타입의 구조분해, 코드펜스 바깥 삽입).

## 진행 방식

**문서 하나씩 끝내고 `PENDING` 에서 뺀다.** 검사기가 "이 문서는 이제 전부 통과한다" 를
출력하므로 그때 목록에서 지운다. 한 문서를 고칠 때마다 검사기를 돌린다.

**편집은 Edit 도구로 한다** — 회차 3에서 줄 번호 기준 bash 삽입이 코드펜스 바깥에
들어가 문서를 깨뜨렸다. 위치를 눈으로 보고 고치는 편이 결국 빠르다.

## 마무리 (이 회차의 종착점)

1. `PENDING` 이 비면 **상수와 관련 분기 코드를 `tests/docs-examples.test.js` 에서 삭제**
2. `CLAUDE.md` 의 PENDING 설명 문단도 삭제 (context 클래스 — `harness allow` 필요)
3. 펜스 균형·펜스 밖 코드 줄 전수 검사 (게이트가 보지 않는 축)
4. 부패 주입으로 게이트 재확인, CI Node 20/22

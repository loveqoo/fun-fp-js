# 회고 — 남은 15건 수리 및 PENDING 제거 (260809-4aef61 · 회차 4/4, 작업 종료)

**완료 조건 8개 전부 충족.** 최종: 347개 실행 / 80개 no-run(이유 없는 것 0) / 실패 0.

## 1. 무엇이 통했나

**회차 3 회고의 규칙을 그대로 따랐다 — "판단이 필요해지면 손".** 남은 15건을 자동화하지
않고 하나씩 열어봤다. 회차 3에서 스크립트가 버그를 두 개 만든 뒤라 이 전환이 명확했다.
결과적으로 15건 중 **9건이 문서가 동작하지 않는 것을 가르치고 있던 경우**였고, 이건
자동화가 절대 찾을 수 없는 종류다:

| 문서 | 잘못 | 실제 |
| --- | --- | --- |
| Reader/State/Writer `composeK` | 평범한 함수를 넘김 | Kleisli 화살표 `a -> M b` 필요 |
| `Traversable.md` | `sequence(traverse, ...)` | 첫 인자는 Traversable **인스턴스** |
| `README.md` | `pipe(값, f, g).fork()` | `pipe` 는 **함수를 돌려준다** |
| `Bifunctor.md` | Task 에 `bimap` | Task 엔 Bifunctor 인스턴스가 **없다** |
| `Free.md` ×2 | `liftF(new Cmd())` | 명령이 **Functor 여야** 한다 (map + 심볼) |

`Free.md` 가 가장 나빴다 — 독자가 그대로 복사하면 즉시 예외인데 그 요구사항이 문서
어디에도 없었다. 실행할 수 없는 블록(네트워크 호출)이라 `no-run` 으로 두면서도
**Functor 요구를 예제에 명시**했다. 실행되지 않아도 가르침은 옳아야 한다.

**각 문서의 이웃 예제를 정답으로 삼았다.** `composeK` 3건은 바로 위 `pipeK` 예제가
올바른 형태를 이미 보여주고 있었다. 새로 발명하지 않고 그 형태를 그대로 가져왔다
(회차 2의 규칙 24 — 문서가 스스로 모순되면 그 문서의 올바른 쪽에 맞춘다).

**게이트가 보지 않는 축을 다시 검사했다.** 회차 3에서 코드펜스 바깥 코드를 교정했는데,
그 정규식이 **구조분해 형태(`const { x } = ...`)를 놓쳐** `Bifunctor.md` 에 한 건이 남아
있었다. 넓은 패턴(`const|let|var|function|class|import|return|if|for`)으로 전수 재검사해
0을 확인했다. **한 번 놓친 패턴은 다시 놓친다 — 검사 패턴 자체를 넓혀야 한다.**

**`PENDING` 을 흔적 없이 지웠다.** 상수, 분기 코드, `CLAUDE.md` 설명까지. 계획에 미리
"남겨두면 다음 사람이 새 문서를 거기 넣는다" 고 적어둔 덕에 잊지 않았다. 유예 장치는
**목적을 다하면 제거되어야 장치다** — 남으면 구멍이 된다.

## 2. 무엇을 잘못 가정했나

**`no-run` 이면 내용은 아무래도 좋다고 잠깐 생각했다.** `Free.md` 를 `no-run` 으로 표시하면서
Functor 요구를 안 적고 넘어갈 뻔했다. 하지만 **`no-run` 은 "실행하지 않는다" 이지
"틀려도 된다" 가 아니다.** 오히려 검사기가 못 잡으므로 사람이 더 조심해야 한다.

**스텁의 타입을 회차 3에서 이미 틀렸는데 회차 4에서도 한 번 더 틀렸다.**
`Bifunctor.md` 에 넣은 `fetchUser` 가 Task 를 돌려주는데 블록은 `Bifunctor.of('either')` 를
쓴다. 자동 스텁이 만든 것이었다. **자동화가 남긴 잔해는 자동화가 끝난 뒤에도 계속 나온다.**

## 3. 이 회차를 싸게 만들었을 것은

**회차 3에서 자동화를 더 일찍 멈췄으면** 이 회차의 절반은 "자동화 잔해 청소" 가 아니라
새 작업이었을 것이다. 52 → 25 구간에서 이미 스크립트가 두 번 버그를 냈다. 그때가 멈출
지점이었다.

**펜스 검사 패턴을 처음부터 넓게 잡았으면** 회차 3에서 한 번에 끝났다. `const\s+\w+\s*=` 로
좁게 잡아 구조분해를 놓쳤다. **검사 패턴은 넓게 잡고 오탐을 걸러내는 편이, 좁게 잡고
놓치는 것보다 낫다.**

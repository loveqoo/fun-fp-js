# 260818 — `git checkout -- index.js` 가 미커밋 구현을 통째로 지웠다

## 무슨 일이 있었나

MonadError 구현이 **아직 커밋되지 않은** 작업 트리 상태에서, 뮤테이션 검증의 복원
단계로 `git checkout -- index.js` 를 실행했다. 이 명령은 뮤테이션 한 줄이 아니라
파일 전체를 HEAD 로 되돌리므로, 커밋 전이던 MonadError 구현 7곳이 index.js 에서
전부 사라졌다.

## 어떻게 알았고, 어떻게 복구했나

- 발견: 복원 직후 재실행한 테스트가 `MonadError.lookup` 자리에서
  `Cannot read properties of undefined` 로 죽었다. 게이트가 즉시 알렸다.
- 복구: 같은 세션에서 재빌드해 둔 `dist/fun-fp.js` 가 구현 전체를 담고 있었다.
  UMD 본문은 index.js 와 거의 자구 그대로이므로, 거기서 7곳을 추출해 count==1
  단언과 함께 재이식했다. 스모크·전체 게이트·baseline 으로 동일성을 재확인했다.
- 오염된 영수증: checkout 직후에 돌린 두 번째 뮤테이션(㉵)의 FAIL 수는 지워진
  index.js 위에서 나온 값이라 무효였다. 복구 후 다시 떴다.

## 규칙

1. **미커밋 변경이 있는 파일에 `git checkout --`/`git restore` 금지.** 뮤테이션
   복원은 심은 것과 같은 표적 치환(count==1 단언)으로만 한다 — 심을 때와 복원할
   때가 같은 도구여야 한다.
2. 뮤테이션 영수증은 **복원 확인까지가 한 세트**다. 복원 직후 재실행이 초록이
   아니면 그 회차의 모든 영수증을 의심한다.
3. dist 는 이 저장소에서 우연히 백업 구실을 했다 — 그러나 이것은 요행이지 체계가
   아니다. 커밋 전 대규모 검증(뮤테이션 배터리)을 돌릴 때는 시작 전에 작업 트리를
   커밋하거나, 최소한 스크래치에 사본을 떠 둔다.
